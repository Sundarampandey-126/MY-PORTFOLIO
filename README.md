# Sundaram Pandey — Portfolio

## Folder structure
- `index.html` — page content and semantic structure
- `css/style.css` — responsive design and visual styling
- `js/script.js` — mobile navigation, scroll reveal, active navigation, and current year
- `images/` — place your profile photo here

## Run locally
1. Keep the folder structure unchanged.
2. Add your photo at `images/my photo.jpeg` (or change the image path in `index.html`).
3. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Before publishing
- Verify the displayed phone number and email address.
- Add links to your real GitHub projects when they are ready.
- Replace the sample project cards with completed projects as you build them.
- The contact section uses `mailto:` and `tel:` links; it does not submit to a backend.

The portfolio uses plain HTML, CSS, and JavaScript. No framework or build step is required.
